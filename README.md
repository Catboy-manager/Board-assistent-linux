# Kanban Board — десктоп-версия (Linux)

Полноценное приложение: канбан-доска + ИИ-ассистент (opencode) + голосовой ввод
(локальное распознавание faster-whisper) в собственном окне, с системным треем и автозапуском.
Сервер встроен и слушает только `127.0.0.1` (внешние устройства сеть не трогают).

## Быстрый старт (dev)

Нужен **Node.js 18+** (проверено на 22).

```bash
cd kanban-desktop/linux
npm install
npm start
```

## Итоговый дистрибутив (AppImage)

```bash
cd kanban-desktop/linux
npm run dist
```

Готовый файл появится в `linux/dist/*.AppImage` — это переносимый исполняемый файл.
Один артефакт можно запускать на любом Linux (без установки):
`chmod +x dist/Kanban*AppImage && ./dist/Kanban*AppImage`.

Для установки по-настоящему (меню, ассоциации) можно добавить target `deb`:
`npm run dist:linux -- --linux deb`.

## Где что лежит

| Что | Путь |
|---|---|
| Данные доски (db.json, config.json, uploads) | `~/.kanban-desktop` |
| Проекты, которые ИИ создаёт/изменяет | `~/AI Projects` |
| Голосовое распознавание (модель осторожно: 75 МБ) | внутри папки приложения `app/stt` |

`db.json` из веб-версии можно перенести вручную:
`cp kanban-board/data/db.json ~/.kanban-desktop/db.json`.

## Зависимости для полной функциональности

- **ИИ-ассистент**: бинарь `opencode` (ставится `curl -fsSL https://opencode.ai/install | bash`)
  в `~/.opencode/bin` — тогда путь находится автоматически. Иначе укажите абсолютный путь
  в конфиге `~/.kanban-desktop/config.json` → `ai.opencodeBin`.
- **Распознавание речи**: `python3` + `pip install faster-whisper pyav` (модель уже внутри папки приложения).
  Если python/whisper нет — голос всё равно запишется и уйдёт ИИ, но без распознавания текста.
- **Озвучка (TTS)**: по умолчанию `espeak-ng` (`sudo apt install espeak-ng`). Для естественного
  голоса поставьте `pip install piper-tts` и положите модель piper в `~/.kanban-desktop/tts/`
  (`ru_RU-irina-medium.onnx` + `.json`, скрипт `piper-ru.py` уже там). Скрипт `tts/скачать-модели.sh`
  в исходниках делает это автоматически.
- **Память и напоминания**: работают из коробки (файлы `memory.json`, `reminders.json` в папке данных).
  В чате: «запомни, что…», «напомни через 10 минут…» — ИИ не вызывается для этого.
- **Системные действия**: буфер обмена (wl-paste/xclip), громкость (pactl), скриншот (X11 `import`
  или GNOME-портал). Под Wayland (GNOME) скриншот может требовать политики портала.

## Возможности системного ассистента (панель 🤖)

- 🔊 — озвучка ответов ИИ серверным TTS (вкл/выкл).
- ⏰ — добавить напоминание (через N минут); при срабатывании — уведомление + озвучка.
- 🧠 — память (факты между диалогами); ПКМ — очистить всю память.
- 📸 — скриншот; 🔉/🔊 — громкость; 📋 — скопировать буфер обмена в строку ввода.
- В **Настройки → ИИ** можно переключить движок: `opencode CLI` или локальный `Ollama` (модель-фолбэк).
- **«Занести в карточки»**: попросите ассистента «занеси в карточки …», «распихай по колонкам …» —
  он вернёт JSON и сервер надёжно разложит пункты в колонки доски (+ опционально факты — в память 🧠).

## Telegram-бот (мост к ассистенту)

- Работает прямо из сервера (без открытия портов): long-poll к `api.telegram.org`.
- Включение: укажите токен от @BotFather в `config.json` (`"telegram": { "token": "...", "allowed": [] }`)
  или окружением `TELEGRAM_TOKEN`. Поле `allowed` — список разрешённых chat-id (пусто = всем в личку).
- Команды: `/status`, `/board`, `/add текст`, `/memo текст`; обычный текст уходит ассистенту
  (отвечает, заносит в карточки, запоминает).
- **Если в вашей сети Telegram заблокирован** (РФ и др.): задайте для сервиса рабочее VPN/прокси —
  модуль использует `HTTPS_PROXY`/`ALL_PROXY` (туннель CONNECT) или свой `TELEGRAM_API_BASE`
  (зеркало/другой хост). Иначе бот пишет «Telegram недоступен» и продолжает ждать.

## Переменные окружения (опционально)

```bash
KANBAN_PORT=8123        # порт встроенного сервера (по умолчанию 8123)
KANBAN_DATA_DIR=...     # папка данных вместо ~/.kanban-desktop
KANBAN_HOST=0.0.0.0     # слушать весь LAN (по умолчанию 127.0.0.1)
```

## Пересылка уведомлений со смартфона

Если задать `KANBAN_HOST=0.0.0.0` (или `host: "0.0.0.0"` в `config.json`), с телефона в той же сети можно слать уведомления на доску: откройте `http://<IP-ПК>:8123/notify.html` либо настройте автоматизацию слать POST на `http://<IP-ПК>:8123/api/notify/send` с JSON `{ "title": "...", "text": "...", "app": "...", "chat": "..." }`.

## Безопасность

- `config.json` (в `~/.kanban-desktop`) содержит секреты (токен Telegram, ключ консоли, ключ ИИ) — **не копируйте и не передавайте** эту папку третьим лицам и не коммитьте. Сборка AppImage их не включает.
- Основные API без авторизации — персональный инструмент для локальной сети; не выходите в интернет без reverse-proxy с аутентификацией.
- Опциональные ключи: `KANBAN_NOTIFY_KEY`, `KANBAN_SMART_KEY`, `KANBAN_CONSOLE_KEY`.

## Как пользоваться

- В трее — иконка: открыть/скрыть окно, открыть в браузере, автозапуск, перезапуск сервера, выход.
- Закрытие окна (крестик) убирает его в трей — приложение продолжает работать.
- Глобальная клавиша `Ctrl+Shift+K` — показать/скрыть окно из любого места.
- Внутри всё как в веб-версии: доска, помощник ИИ (панель справа), голос — кнопка 🎙️ (нажмите, говорите, пауза отправит сама), вкладка 📁 — файлы проектов, вкладка 🔔 — уведомления.
- **Голосовая активация (wake-слово) отключена** — голосовой ввод в чате работает, но постоянное прослушивание не подключается.
